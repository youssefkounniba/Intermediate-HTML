# Intermediate HTML Exercise

## 📚 Project Overview

This is my intermediate HTML project as part of the **Geeks Institute AI Full Stack Bootcamp**. The project demonstrates more advanced HTML concepts including forms, tables, and semantic HTML5 elements.

## 🎯 Learning Objectives

Through this exercise, I learned:
- Semantic HTML5 elements (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`)
- Creating navigation menus with links
- Building HTML tables with proper structure
- Creating complex forms with various input types:
  - Text inputs
  - Email inputs
  - Date inputs
  - Checkboxes
  - Radio buttons
  - Submit buttons
- Proper form labels and accessibility
- Organizing content with semantic sections

## 🛠️ Technologies Used

- HTML5

## 📋 Project Features

The webpage includes:

### 1. **Header with Navigation**
- Navigation bar with essential links (Home, About, Contact)

### 2. **Main Content Section**
- **Article 1**: Programming languages history table
  - Displays languages created in 1995 (JavaScript, Java, PHP, Ruby)
  - Includes language name, designer, and year of first appearance
- **Article 2**: Placeholder for future content

### 3. **Contact Form**
- Personal information fields (First Name, Last Name, Email, Date of Birth)
- Work type selection using checkboxes (Programming, Design, Singing, Comedy)
- Interest level selection using radio buttons (Very Low to Very High)
- Submit button

### 4. **Footer**
- Copyright information

## 🚀 How to View

Simply open the `index.html` file in any modern web browser to view the complete page.

## 💡 Key Concepts Demonstrated

- **Semantic HTML**: Using appropriate HTML5 semantic elements for better structure and accessibility
- **Tables**: Creating structured data presentation with `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, and `<td>`
- **Forms**: Building interactive forms with various input types and proper labeling
- **Form Controls**: 
  - Text and email inputs for data collection
  - Date picker for birth date
  - Checkboxes for multiple selections
  - Radio buttons for single selection from multiple options
- **Navigation**: Implementing site navigation structure
